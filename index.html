    Where the files go
    
    
    
      
    
        
    user.cfg
    
        
    The game's install folder, in the same folder as bf4.exe:
    
        
    
        
      
          
    • EA app: right-click the game > View properties > Browse.
      • 
          
    • Steam: right-click the game > Manage > Browse local files.
      • 
          
    • Make sure Windows doesn't save it as user.cfg.txt.
      • 
          
    • It's optional. If the game runs worse with it, delete it.
      • 
        
    
      
    
      
    
        
    PROFSAVE_profile
    
        
    Your Documents folder:
    
        
    
        
    If the settings folder has a steam, ea or epic subfolder, use the PROFSAVE_profile inside the one for your launcher.
    
        
      
          
    • Close the game first. It rewrites this file when it exits.
      • 
          
    • Back up the old file before replacing it.
      • 
          
    • Changing video options in-game later overwrites these values.
      • 
        
    
      
    
    
    
  
    

  
    
    
    Driver settings
    
    
    
  
    

  
    
    
    On Windows? Two apps, no install
    
    
    Both are single, readable .cmd files that detect your hardware for you, copy the files into the game with a backup, and can undo it. Download them from the latest release.
    
    
      
      
    • Battlefield_Optimizer_v2.2.1.cmd: a guided run in the console for all four games. Pick the game, confirm G-Sync / FreeSync, and it does the rest.
      • 
      
    • Battlefield_Optimizer_GUI_v2.2.1.cmd: the same engine in a window. Choose the graphics tier, the FPS cap and every tweak (motion blur, lens effects, depth of field, visibility, V-Sync, frame generation, DirectX 11 and more) with checkboxes, preview the changes, then apply or undo. Keep it in the same folder as the script.
      • 
    
    
    
    The script and the GUI give the same results for the same choices. See the changelog for what's new.
